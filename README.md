# CreatorSync 🚀

CreatorSync is a comprehensive Full-Stack Development (FSD) platform designed to bridge the gap between content creators and brands. It streamlines influencer marketing campaigns, workspace collaboration, analytics tracking, and communication pipelines into a singular, efficient hub.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS / Custom CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (via Mongoose)
- **Authentication:** JSON Web Tokens (JWT)
